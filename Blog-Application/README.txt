# MyBlog beginner project

## Run the project
1. Extract this ZIP file.
2. Open the `Blog-Application` folder in Visual Studio Code.
3. In VS Code, open Extensions (Ctrl+Shift+X), search for **Live Server**, and install it.
4. Open `index.html`.
5. Right-click inside the file and select **Open with Live Server**.
6. The website opens in your browser. Register, then create and publish blog posts.

## Pages
- `index.html` — Home page
- `login.html` — Login page
- `register.html` — Registration page
- `dashboard.html` — User dashboard
- `create-blog.html` — Create blog page
- `css/style.css` — Design and responsive layout
- `js/app.js` — Registration, login, and blog post functions

## Important
This is a beginner frontend demo. It stores users and blog posts in the browser's localStorage. It is not secure for real users because passwords are not protected by a backend. A real deployment needs a backend, database, and secure authentication.
